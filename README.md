\## 📝 What is Markdown?



Markdown is a lightweight markup language that allows us to format

plain text using simple symbols.



Markdown files normally use the `.md` extension.



\## ✨ Text Formatting



\### Bold



\*\*This text is bold.\*\*



\### Italic



\*This text is italic.\*



\### Bold and Italic



\*\*\*This text is bold and italic.\*\*\*



\### Strikethrough



\~\~This text is crossed out.\~\~
